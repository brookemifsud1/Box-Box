# Box-Box
Creative Coding A2 Project

<b>Project Link (Main Submission)</b>

Primary Access URL: https://makecode.com/_eJLfsmJytFKF

- Click the link above to open and run BOX BOX directly in your web browser via the Microsoft MakeCode Arcade simulator. 
- This link provides instant access to play the game, test the pitstop mechanics, inspect the full Python code, and view the visual assets online without requiring any software installation or file downloads.


<b>Running on Physical Hardware (TinkerGen GameGo)</b>

- Connect your TinkerGen GameGo device to your computer using a micro-USB cable
- Drag and drop the arcade-Creative-Coding-A2-Box-Box.uf2 file into the GameGo USB drive folder
- The device will flash the program and reboot, launching BOX BOX on the console

<b>Repository Files Guide</b>
Additional files have been provided in the repository as technical backups and physical hardware builds:

- arcade-Creative-Coding-A2-Box-Box.uf2: The TinkerGen GameGo file to play BOX BOX on physical handheld hardware  
- makecode-arcade-code: The raw, uncompiled Python source code backup file for direct code inspection in any text editor
- pitlane.bmp: The backup bitmap image file of the custom pixel-art pitlane background
- car.bmp: The backup bitmap image file of the player's red racing car sprite
- box.bmp: The backup bitmap image file of the pitbox outline sprite used for collision detection
